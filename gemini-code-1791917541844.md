# 🧪 Tabla Periódica de los Verbos Irregulares en Inglés

Una aplicación web interactiva inspirada en la tabla periódica para aprender y repasar los verbos irregulares en inglés organizados por patrones gramaticales.

## 🌟 Características
- 🎨 **Diseño estilo Tabla Periódica:** Organización cromática por familias de verbos (Invariables, -OUGHT/-AUGHT, I-A-U, Participio en -EN, etc.).
- 🔍 **Modo Exploración:** Haz clic en cualquier casilla para ver todas las formas verbales y traducción.
- ⚡ **Ligero y Rápido:** Desarrollado exclusivamente con HTML, CSS y JavaScript sin dependencias externas.
